# Requisitos do Sistema

## Requisitos funcionais

RF01 — O sistema deve permitir autenticação por e-mail e senha.
RF02 — O administrador deve poder cadastrar usuários.
RF03 — O usuário deve poder abrir chamados.
RF04 — O sistema deve permitir consultar chamados.
RF05 — O sistema deve permitir buscar chamados por texto.
RF06 — O sistema deve permitir filtrar por status e prioridade.
RF07 — Agentes e administradores devem poder alterar o status.
RF08 — Usuários autorizados devem poder comentar chamados.
RF09 — Administradores devem poder excluir chamados.
RF10 — O sistema deve apresentar indicadores no dashboard.
RF11 — O sistema deve calcular SLA conforme a prioridade.

## Requisitos não funcionais

RNF01 — Senhas devem ser armazenadas com hash.
RNF02 — Rotas protegidas devem exigir autenticação.
RNF03 — Operações administrativas devem exigir autorização.
RNF04 — O sistema deve persistir os dados em banco.
RNF05 — A interface deve ser responsiva e legível.
RNF06 — O projeto deve ser executável localmente com documentação.
