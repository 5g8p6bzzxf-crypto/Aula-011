# Estratégia de Testes

Casos principais para validação:

1. Login com credenciais corretas.
2. Login com credenciais incorretas.
3. Usuário abre chamado.
4. Sistema rejeita título curto.
5. Sistema rejeita descrição curta.
6. Chamado recebe SLA conforme prioridade.
7. Agente altera status.
8. Usuário comum não acessa administração.
9. Administrador cadastra usuário.
10. Administrador exclui chamado.
11. Comentário é persistido.
12. Busca e filtros retornam chamados compatíveis.

## Checklist de aceitação

- [ ] Login funcionando
- [ ] Dashboard funcionando
- [ ] Cadastro de chamado funcionando
- [ ] Listagem e filtros funcionando
- [ ] Comentários funcionando
- [ ] Status funcionando
- [ ] Usuários funcionando
- [ ] Autorização funcionando
- [ ] Banco persistindo dados
