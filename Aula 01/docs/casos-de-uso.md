# Casos de Uso

## UC01 — Autenticar usuário
Ator: qualquer usuário cadastrado.
Fluxo: informar e-mail e senha → validar credenciais → acessar dashboard.

## UC02 — Abrir chamado
Ator: usuário autenticado.
Fluxo: informar título, descrição, categoria e prioridade → validar → calcular SLA → salvar.

## UC03 — Gerenciar chamado
Ator: agente ou administrador.
Fluxo: abrir chamado → alterar status → salvar alteração.

## UC04 — Comentar chamado
Ator: usuário autorizado.
Fluxo: abrir chamado → escrever comentário → salvar.

## UC05 — Gerenciar usuários
Ator: administrador.
Fluxo: abrir área administrativa → cadastrar usuário → validar → salvar.

## UC06 — Consultar chamados
Ator: usuário autenticado.
Fluxo: acessar lista → pesquisar/filtrar → abrir detalhes.
